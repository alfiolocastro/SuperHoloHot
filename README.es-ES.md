

# SuperHoloHot

En los últimos días he tenido un Hololens2 entre manos. Me encantó SuperHOT (pc, consola, VR) y tenía curiosidad por ver cómo sería en la vida real, es algo que quiero hacer desde que los primeros dispositivos de realidad aumentada estuvieron accesibles.
Creo que el Hololens es una opción perfecta para este propósito (manos libres, un GPU decente, una muy buena percepción y comprensión espacial) y este video https://youtu.be/1pQrcX15480 muestra lo que logré después de un día de desarrollo en mi [tiempo libre] usando Unity3d y MRTK.

La idea es crear un juego "completo" con editor de niveles y totalmente jugable en cualquier contexto (habitación, espacios abiertos)
